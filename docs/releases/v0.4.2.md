Haunt 0.4.2: exporting a picture as PNG works in the app. It is still in development: expect rough edges, and expect things to change between versions before 1.0. This is a pre-release; it becomes the latest release once it has had some use.

## Fixed

- **Export as PNG.** Exporting the Graph as a PNG image failed with "The source image cannot be decoded": the window only lets images load from the app itself, and the picture was handed over in a way it does not allow. It now works; exporting as SVG already did.

## Install

| System | File |
|---|---|
| Windows | `Haunt_0.4.2_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon | `Haunt_0.4.2_aarch64.dmg` |
| macOS, Intel | `Haunt_0.4.2_x64.dmg` |
| Linux | `.deb` (Debian, Ubuntu), `.rpm` (Fedora), or the `.AppImage` |
| Arch, CachyOS | `haunt-bin-0.4.2-1-x86_64.pkg.tar.zst`: download it, then `sudo pacman -U` it |

Haunt needs git 2.24 or later (Repair links needs 2.29). For TypeScript and JavaScript it uses Node 22.18 or later, or else Bun or Deno; without any of them it still reads the other languages.

## Known limits

The same as 0.3.0: the installers are not signed yet, the Linux additions have seen little use on a real desktop, and `haunt-bin` is not on the AUR yet. See the [0.3.0 notes](https://github.com/razerghost/haunt/releases/tag/v0.3.0). On Windows the folder of the repository on screen cannot be renamed while Haunt watches it; switch to another tab first.

Found a problem? Please [open an issue](https://github.com/razerghost/haunt/issues).
