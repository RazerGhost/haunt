Haunt 0.3.3: no more endless rescans on Linux. It is still in development: expect rough edges, and expect things to change between versions before 1.0. This is a pre-release; it becomes the latest release once it has had some use.

## Fixed

- **Linux: rescanning about every second.** On Linux Haunt took its own scanner reading the files for changes to them, so each scan started the next one, in any repository, with nothing being edited. Only real changes start a scan now: a file written, added, removed or renamed.
- The spinner under the commit list no longer flashes on every refresh; it shows only when reading the list takes a moment.

## Install

| System | File |
|---|---|
| Windows | `Haunt_0.3.3_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon | `Haunt_0.3.3_aarch64.dmg` |
| macOS, Intel | `Haunt_0.3.3_x64.dmg` |
| Linux | `.deb` (Debian, Ubuntu), `.rpm` (Fedora), or the `.AppImage` |
| Arch, CachyOS | `haunt-bin-0.3.3-1-x86_64.pkg.tar.zst`: download it, then `sudo pacman -U` it |

Haunt needs git 2.24 or later. For TypeScript and JavaScript it uses Node 22.18 or later, or else Bun or Deno; without any of them it still reads the other languages.

## Known limits

The same as 0.3.0: the installers are not signed yet, the Linux additions have seen little use on a real desktop, and `haunt-bin` is not on the AUR yet. See the [0.3.0 notes](https://github.com/razerghost/haunt/releases/tag/v0.3.0).
