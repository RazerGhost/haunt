Haunt 0.4.0: one Graph for the code, and a Git side that says where you are. It is still in development: expect rough edges, and expect things to change between versions before 1.0. This is a pre-release; it becomes the latest release once it has had some use.

## New

- **The Graph.** The Code side's Layers, Canvas, Calls and Imports are now one page. Files are cards, their functions are rows, and the calls between the rows are lines. It opens on the project: the parts in a column per layer, left to right, with the files that import across them and the imports judged by the project's rules (breaks in red, accepted ones in amber, runtime cycles listed, **Over time** as before). From there, focus on a part (its files, the files outside it grouped by part, **Who knows it** on request), a file (all its functions; bookmark it), or a function: what calls it on the left and what it calls on the right, or **Paths** from the entry points, with **Predict**. Only the rows on a line show; the rest fold into "N more · Show". **Start from** lists the most called functions, the entry points and your recent ones, and typing in the search box opens it.
- **Show** in the Graph's toolbar adds the imports between the files shown, marks what you learned (**Familiarity**) and tints busy files (**Hotspots**). **Export** saves the graph as a PNG or SVG image.
- **Where you are.** A detached HEAD reads "Detached at a1b2c3d (v1.2)" in the toolbar, with a way back to the branch you left, a new branch here, or a recent branch. The commit box says which branch a commit goes to.
- **A branch far apart from its remote branch** gets a note above All commits: how far, whether its history was most likely rewritten, and the safe steps (see the commits only here, keep a copy and match the remote, or rebase).
- **Already in the main line.** Commits of other branches whose changes the main line already has (cherry-picked, rebased, or a whole squash-merged branch) are dimmed, with a link to the commit that has them. More filters can hide those branches, and Branch cleanup offers them.

## Better

- **Big graphs stay smooth.** Lines are drawn on a canvas, many lines between the same two cards become one, and panning moves one layer. Shade's largest part opens and pans without lag.
- **A quieter commit list.** A branch and its remote branch on one commit share one chip, long branch names are shortened in the middle, and with one author on nearly every commit the author column shows initials.
- **A quieter sidebar.** On the Git side each local branch shows its remote state inline, Remotes lists only remote branches no local branch tracks, and long tag lists start folded. The Code side lists Graph, Unused and Routes, and its parts open their graph.
- **The search box follows the side you are on:** "Find a commit" on the Git side, "Find a function" on the Code side.

## Removed

- The Layers, Canvas, Calls and Imports pages, now the Graph, and the Map, Calls and Architecture lenses of a commit's details. "Last changed" next to every function and the per-part "% understood" on the layer tiles went with them; a function's own panel still shows who wrote it and its history.

## Install

| System | File |
|---|---|
| Windows | `Haunt_0.4.0_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon | `Haunt_0.4.0_aarch64.dmg` |
| macOS, Intel | `Haunt_0.4.0_x64.dmg` |
| Linux | `.deb` (Debian, Ubuntu), `.rpm` (Fedora), or the `.AppImage` |
| Arch, CachyOS | `haunt-bin-0.4.0-1-x86_64.pkg.tar.zst`: download it, then `sudo pacman -U` it |

Haunt needs git 2.24 or later (Repair links needs 2.29). For TypeScript and JavaScript it uses Node 22.18 or later, or else Bun or Deno; without any of them it still reads the other languages.

## Known limits

The same as 0.3.0: the installers are not signed yet, the Linux additions have seen little use on a real desktop, and `haunt-bin` is not on the AUR yet. See the [0.3.0 notes](https://github.com/razerghost/haunt/releases/tag/v0.3.0). On Windows the folder of the repository on screen cannot be renamed while Haunt watches it; switch to another tab first.

Found a problem? Please [open an issue](https://github.com/razerghost/haunt/issues).
