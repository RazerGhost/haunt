Haunt 0.3.6: learn a codebase, not just look at it. It is still in development: expect rough edges, and expect things to change between versions before 1.0. This is a pre-release; it becomes the latest release once it has had some use.

## New

- **Track what you understand.** Mark a function as understood from its panel, or learn it through the exercises below. Haunt remembers it per repository, on your computer only, and shows it as stale once its code changes.
- **Routes as flashcards.** Hide chains covers each route's call chain until you click it; then say whether you knew it. Shuffle deals the routes again.
- **Predict the call path.** On Calls → Paths, Predict hides the functions between the entry points and the target. Fill the places from the real functions mixed with decoys, then Reveal grades your picks.
- **Familiarity on the Canvas**, next to Hotspots and together with it: grey until learned, green when familiar, amber when stale. The Layers sidebar shows the share understood per part.
- **Who knows it, with AI co-authorship.** Blamed lines are split into yours alone, AI co-authored (a commit with a matching `Co-Authored-By` trailer) and other authors, on part pages and now per function too. Which co-authors count is set in `haunt.config.json` under `"attribution": { "ai": [...] }`; by default anything naming Claude or anthropic.com.

## Better

- **Calls without test code.** Most called, the caller counts and the graphs leave test files and test helpers out unless "Include tests" is on; the function panel lists callers from tests in a folded group.
- **Readable graphs.** Calls and Imports open on the chosen function and its neighbours at a readable zoom, hide labels too small to read (hover a node for its name), and have a Fit button for the whole graph.
- **Linux, NVIDIA on Wayland:** Haunt switches WebKitGTK's DMA-BUF renderer off there, which leaves some of these setups with a blank window, unless you set `WEBKIT_DISABLE_DMABUF_RENDERER` yourself.

## Fixed

- Bisect: testing a commit you picked yourself failed on git 2.39 and other older versions.
- Stopping a long git command on Linux and macOS no longer depends on the `kill` program being installed.

## Install

| System | File |
|---|---|
| Windows | `Haunt_0.3.6_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon | `Haunt_0.3.6_aarch64.dmg` |
| macOS, Intel | `Haunt_0.3.6_x64.dmg` |
| Linux | `.deb` (Debian, Ubuntu), `.rpm` (Fedora), or the `.AppImage` |
| Arch, CachyOS | `haunt-bin-0.3.6-1-x86_64.pkg.tar.zst`: download it, then `sudo pacman -U` it |

Haunt needs git 2.24 or later. For TypeScript and JavaScript it uses Node 22.18 or later, or else Bun or Deno; without any of them it still reads the other languages.

## Known limits

The same as 0.3.0: the installers are not signed yet, the Linux additions have seen little use on a real desktop, and `haunt-bin` is not on the AUR yet. See the [0.3.0 notes](https://github.com/razerghost/haunt/releases/tag/v0.3.0). The NVIDIA workaround has not been tried on a real NVIDIA machine yet.

Found a problem? Please [open an issue](https://github.com/razerghost/haunt/issues).
