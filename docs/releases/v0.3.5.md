Haunt 0.3.5: projects on TypeScript 7 scan again. It is still in development: expect rough edges, and expect things to change between versions before 1.0. This is a pre-release; it becomes the latest release once it has had some use.

## Fixed

- **TypeScript 7 projects.** In a trusted folder Haunt reads a project with the project's own TypeScript, and TypeScript 7 (the native compiler) has no compiler API to read with, so the scan failed with "typescript.getParsedCommandLineOfConfigFile is not a function". Haunt now checks first: for TypeScript 7 it reads the project with its own TypeScript, tsconfig files and their `extends` included, and says so. Projects on TypeScript 5 and 6 are read with their own, as before.

## Install

| System | File |
|---|---|
| Windows | `Haunt_0.3.5_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon | `Haunt_0.3.5_aarch64.dmg` |
| macOS, Intel | `Haunt_0.3.5_x64.dmg` |
| Linux | `.deb` (Debian, Ubuntu), `.rpm` (Fedora), or the `.AppImage` |
| Arch, CachyOS | `haunt-bin-0.3.5-1-x86_64.pkg.tar.zst`: download it, then `sudo pacman -U` it |

Haunt needs git 2.24 or later. For TypeScript and JavaScript it uses Node 22.18 or later, or else Bun or Deno; without any of them it still reads the other languages.

## Known limits

The same as 0.3.0: the installers are not signed yet, the Linux additions have seen little use on a real desktop, and `haunt-bin` is not on the AUR yet. See the [0.3.0 notes](https://github.com/razerghost/haunt/releases/tag/v0.3.0).

Found a problem? Please [open an issue](https://github.com/razerghost/haunt/issues).
