Haunt 0.2.0: in English and Dutch, with a repository manager, the reflog, and five more languages. It is still in development: expect rough edges, and expect things to change between versions before 1.0. This is a pre-release; it becomes the latest release once it has had some use.

## New

- **Dutch.** The whole window is in English or Dutch (Settings, General; it starts as your system's language), Haunt's own messages included. Dates and numbers follow the language.
- **Repository manager**, in place of the open screen (Ctrl O, or the + beside the tabs): your recent repositories and every repository in the folders you add, as a tree; the one picked at a glance (uncommitted files, commits, first and last commit, remotes with their pages, branches, tags, latest commits), its statistics and its README. **Clone** a URL or make a **New** repository from there.
- **Remotes**: add, rename and remove them and change their URL, from the sidebar or the repository manager.
- **Reflog** (More, or the palette): where HEAD or a branch pointed, newest first, with the commits only the reflog still keeps marked as lost; put a branch on one, reset to it or cherry-pick it.
- **Local changes**: ignore an untracked file, its extension or its folder; stash only the files you tick; diffs side by side too. With nothing changed, it shows what is left to push or pull, the last commit (Amend) and your stashes.
- **New pull request** through `gh` or `glab`, its title and description made from the branch's commits.
- **Search files** at any commit (`git grep`): text, a regular expression or a whole word.
- **Signed commits**: marked in the commit list and checked in a commit's details, with your own gpg or ssh-keygen settings, never the repository's.
- **Code map**: bookmark files; see who changed each function last; export the canvas or the layer map as PNG or SVG.
- **Java, C#, Ruby, C and C++**, read with tree-sitter next to PHP, Rust, Lua, Python and Go.

## Better

- The commit list has the whole screen until you pick a commit; the rarer filters fold into More filters.
- File names stay whole in narrow lists; side by side switches to unified where it would not fit.
- The palette has every action with its shortcut, and **?** lists all the shortcuts. Buttons with only an icon say what they do on hover and on keyboard focus.
- An error stays until you close it, with Copy.
- The repository manager opens a repository's overview in about a third of the time, and the recent list and your repository folders come up at once from what was read last.

## Fixed

- A write that hangs (a commit hook waiting for input) no longer blocks its repository until Haunt restarts: it stops after 10 minutes, or when you press Stop, with everything it started.
- A closed repository is let go: on Windows its folder can be moved or deleted while Haunt runs.
- A crash in one command can no longer leave Haunt unable to do anything until it is restarted.

## Install

| System | File |
|---|---|
| Windows | `Haunt_0.2.0_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon | `Haunt_0.2.0_aarch64.dmg` |
| macOS, Intel | `Haunt_0.2.0_x64.dmg` |
| Linux | `.deb` (Debian, Ubuntu), `.rpm` (Fedora), or the `.AppImage` |

Haunt needs git 2.24 or later. For TypeScript and JavaScript it uses Node 22.18 or later, or else Bun or Deno; without any of them it still reads the other languages.

## Known limits

- The installers are not signed yet: Windows SmartScreen and macOS Gatekeeper warn the first time you open Haunt.
- This version was tested on Windows. The macOS and Linux builds compile but have seen little use; on Linux, a blank window on some NVIDIA or Wayland setups can be worked around with `WEBKIT_DISABLE_DMABUF_RENDERER=1`.
- Java, C#, Ruby, C and C++ were tried on small test projects only. Gitea (pull request status, and new pull requests through `tea`) is untested.
- Haunt looks for updates only when you switch that on in Settings, and then links to the new version; it does not update itself.
