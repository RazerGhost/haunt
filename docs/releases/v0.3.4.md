Haunt 0.3.4: the small things you do all day, quicker. It is still in development: expect rough edges, and expect things to change between versions before 1.0. This is a pre-release; it becomes the latest release once it has had some use.

## New

- **Pick several at once.** Ctrl-click and Shift-click (Shift ↑ ↓ in Local changes, Ctrl A for a whole list) pick several:
  - files in Local changes, to stage, unstage, discard or stash together, or drag them onto the other list;
  - stashes to drop, and Recently dropped or Recently discarded entries to bring back;
  - branches and tags to delete (and tags to push);
  - conflicted files, to take your side or theirs for all of them.
- **Commit and push** in one go (Ctrl Shift Enter).
- **Branches you are not on**: compare one with yours, push it, or bring it up to its remote branch (only as a fast-forward), from its right-click menu.
- **Find in a diff.** Ctrl F in a diff, code, blame or a commit's message finds in that text; elsewhere it is still the function search.
- **Open a file from its menu**: Open in editor, Show in folder and Copy path, in Local changes and in a commit's files.

## Better

- **Keys**: Ctrl Tab and Ctrl Shift Tab go to the next and previous tab, Alt 1 to 9 to a tab by its place, and Ctrl W closes it; in Local changes, Delete discards (asked first) and Enter opens the file in your editor; Ctrl C copies a picked commit's sha. The **?** sheet lists them all.
- **Ctrl A** selects within the place you are in (a list's items, a diff's text), no longer the whole window.
- The file column of Local changes can be dragged wider, and keeps its width.
- Each tab keeps its place in the commit list.
- The conflict view opens any conflicted file in your editor, not only the ones Haunt's scan reads.

## Install

| System | File |
|---|---|
| Windows | `Haunt_0.3.4_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon | `Haunt_0.3.4_aarch64.dmg` |
| macOS, Intel | `Haunt_0.3.4_x64.dmg` |
| Linux | `.deb` (Debian, Ubuntu), `.rpm` (Fedora), or the `.AppImage` |
| Arch, CachyOS | `haunt-bin-0.3.4-1-x86_64.pkg.tar.zst`: download it, then `sudo pacman -U` it |

Haunt needs git 2.24 or later. For TypeScript and JavaScript it uses Node 22.18 or later, or else Bun or Deno; without any of them it still reads the other languages.

## Known limits

The same as 0.3.0: the installers are not signed yet, the Linux additions have seen little use on a real desktop, and `haunt-bin` is not on the AUR yet. See the [0.3.0 notes](https://github.com/razerghost/haunt/releases/tag/v0.3.0).
