Haunt 0.3.1: open the repository in your editor. It is still in development: expect rough edges, and expect things to change between versions before 1.0. This is a pre-release; it becomes the latest release once it has had some use.

## New

- **Open in your editor.** A button in the toolbar, on the Git and Code screens alike, opens the repository's folder in the editor picked in Settings, General: "Open in Zed", "Open in VS Code" and so on. It is also in a tab's right-click menu and the palette, and on Ctrl Shift A (⌘ Shift A on macOS). A custom editor's command gets the folder in place of `{file}`; one that runs in a terminal opens in your terminal.

## Install

| System | File |
|---|---|
| Windows | `Haunt_0.3.1_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon | `Haunt_0.3.1_aarch64.dmg` |
| macOS, Intel | `Haunt_0.3.1_x64.dmg` |
| Linux | `.deb` (Debian, Ubuntu), `.rpm` (Fedora), or the `.AppImage` |
| Arch, CachyOS | `haunt-bin-0.3.1-1-x86_64.pkg.tar.zst`: download it, then `sudo pacman -U` it |

Haunt needs git 2.24 or later. For TypeScript and JavaScript it uses Node 22.18 or later, or else Bun or Deno; without any of them it still reads the other languages.

## Known limits

The same as 0.3.0: the installers are not signed yet, the Linux additions have seen little use on a real desktop, and `haunt-bin` is not on the AUR yet. See the [0.3.0 notes](https://github.com/razerghost/haunt/releases/tag/v0.3.0).
